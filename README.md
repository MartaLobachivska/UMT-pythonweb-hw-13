## Запуск

1. Скопіюй `.env.example` у `.env` і заповни всі значення `your_...` / `replace_...`. Не комітьте `.env`.
2. З цієї папки запусти:
```bash
   docker compose up --build
```
3. Відкрий `http://localhost:8000/docs` (Swagger UI).

База даних і Redis працюють у Docker. `DATABASE_URL` має використовувати хост `db`, коли API запущено в Docker, як показано в `.env.example` — це лишається `db:5432`, навіть якщо ти зміниш зовнішній (host) порт (див. нижче).

> **Порт вже зайнятий?** Якщо `5432` або `8000` вже зайняті на твоїй машині іншим Postgres/API-процесом, зміни тільки ліву (host) частину в `docker-compose.yml`, наприклад `"5433:5432"` для `db` або `"8001:8000"` для `api`. Права частина (внутрішній порт контейнера) має лишитись без змін, а `DATABASE_URL`/`REDIS_URL` у `.env` міняти взагалі не треба — вони стосуються внутрішньої мережі Docker.
